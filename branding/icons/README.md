# OnRouteWay application icon

The source artwork is the user-supplied `GranbellPQC.png`, copied without modification to `OnRouteWay.png`. It is a 1024×1024 RGBA PNG with an alpha channel and transparent corner pixels; the artwork itself visibly reads “GRANBELL POST-QUANTUM BROWSER”.

Prepared formats:

- `OnRouteWay.png` — original-resolution PNG for Linux and general use.
- `OnRouteWay.ico` — multi-size Windows icon.
- `OnRouteWay.icns` — macOS icon container.

Creator attribution: **Created by Silva Rosa Corporation for Granbell Financial Services.**

These are project assets. Chromium source is not checked out in this workspace, so the icons have not yet been embedded in a built application bundle or executable.
