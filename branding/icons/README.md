# OnRouteWay edition-specific application icons

Use the icon for the selected edition; do not substitute a shared/default icon.

## QDFS Edition

Source: user-supplied `GranbellPQC-1.png`, copied byte-for-byte as `qdfs/GranbellPQC.png`.

- `qdfs/GranbellPQC.png` — original-resolution 1024×1024 RGBA PNG.
- `qdfs/GranbellPQC.ico` — multi-size Windows icon.
- `qdfs/GranbellPQC.icns` — macOS icon container.

The artwork visibly carries the Granbell post-quantum browser emblem.

## Private Edition

Source: user-supplied `ORW_Browser.png`, copied byte-for-byte as `private/ORW_Browser.png`.

- `private/ORW_Browser.png` — original-resolution 1024×1024 RGBA PNG.
- `private/ORW_Browser.ico` — multi-size Windows icon.
- `private/ORW_Browser.icns` — macOS icon container.

The artwork carries the OnRouteWay route-and-shield mark and wordmark.

Both source images are RGBA PNGs with transparency. The ICO and ICNS files are derived from the corresponding source image; no artwork was redrawn or altered. Edition-to-icon paths are recorded in `branding/app_identity.json`, `global/config.public.yaml`, and the private `global/config.global.yaml`.

Creator attribution: **Created by Silva Rosa Corporation for Granbell Financial Services.**

These are prepared project assets, not proof of native integration. Chromium source is not checked out in this workspace, so neither icon has yet been embedded in a built browser executable or application bundle.
