What is PQC?

Post-quantum cryptography (PQC) is cryptography designed to resist attacks by quantum computers as well as classical computers. No algorithm can be described as absolutely secure against every future attack. ML-DSA-65 is a digital-signature algorithm standardised in NIST FIPS 204; it is distinct from a TLS key-exchange algorithm. The PQC indicator reports properties verified for the current connection, not a general guarantee about a website.

What is the QDFS network?

QDFS is Silva Rosa Corporation's distributed network using IPFS peer connectivity. The QDFS indicator reports only verified peer membership, the network path's IP family and whether the QDFS CA validated the relevant certificate. An IPFS installation by itself does not prove QDFS membership.
